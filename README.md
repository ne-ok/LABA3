# ПРОЕКТ
Проект состоит из 2 веток:
1) **redis_main**: реализация с использованием PostgreSQL.
   
2) **postgres**: реализация с использованием Redis.

# Инструкция использования
## Требования:
 - *Python 3.9+*
 - * *
 - *PostgreSQL (для ветки main)*
 - *Redis (для ветки redis-cache)*
## ЭТАПЫ:
**1.Установите зависимости**:
pip install -r requirements.txt
**2.Проверьте настройки конфигурации баз данных**:
  - Для PostgreSQL убедитесь, что указаны правильные учётные данные и название базы данных.
  - Для Redis проверьте доступность службы Redis.
**4.Запустите сервер**:
uvicorn main:app --reload
**5.Откройте браузер и перейдите по адресу**:
http://127.0.0.1:8000/docs, чтобы посмотреть документацию Swagger.
